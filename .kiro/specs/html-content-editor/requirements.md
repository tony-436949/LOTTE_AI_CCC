# 요구사항 문서

> **구현 파일:** `AI_CCC.html` (프로젝트 루트)
> 원래 `Editor/editor.html`로 계획되었으나, 최종 구현 시 루트 레벨의 `AI_CCC.html` 단일 파일로 변경되었다.

## 소개

롯데백화점 내부 영업 직원이 백화점 APP 및 PC/MO 홈페이지에 등록할 HTML 콘텐츠를 브라우저에서 직접 편집할 수 있는 WYSIWYG 인라인 에디터이다. 사용자는 기존 HTML ZIP 파일을 업로드하여 미리보기하고, 이미지·슬라이드·텍스트·탭 구성 등의 소스 영역을 추가·삭제·순서 변경한 뒤, 동일한 ZIP 형식으로 다운로드한다. 별도 서버 설치 없이 HTML 파일을 브라우저에서 열어 바로 사용할 수 있어야 한다.

## 용어 정의

- **에디터**: 브라우저에서 동작하는 WYSIWYG HTML 콘텐츠 편집 도구 전체를 지칭한다
- **ZIP_파서**: 업로드된 ZIP 파일을 읽어 내부 파일 구조(index.html, css/, js/, images/)를 메모리에 파싱하는 모듈이다
- **ZIP_생성기**: 편집 완료된 콘텐츠를 원본 ZIP과 동일한 디렉터리 구조로 재조립하여 ZIP 파일로 출력하는 모듈이다
- **소스_영역**: 편집 가능한 콘텐츠 단위로, 이미지 블록·슬라이드 블록·텍스트 블록·링크 블록 중 하나에 해당한다
- **미리보기_영역**: 업로드된 HTML 콘텐츠를 실제 렌더링 결과와 유사하게 표시하는 화면 영역이다
- **탭_구성**: `tab-btn-area`와 복수의 `tab-area`로 이루어진 탭 기반 콘텐츠 구조이다. 각 탭은 on/off 이미지 쌍과 해당 콘텐츠 영역을 포함한다
- **슬라이드_블록**: Swiper 라이브러리 기반의 `swiper-mask` 구조로, 복수의 슬라이드 이미지를 좌우 스와이프로 탐색하는 영역이다
- **이미지_블록**: `<img>` 태그 단독 또는 `img-box` 클래스로 감싸진 이미지 표시 영역이다
- **링크_블록**: `<a>` 태그로 감싸진 이미지로, `link-btn` 클래스와 `linkObj` 데이터를 통해 외부 링크를 연결하는 영역이다
- **eventBox**: 모든 콘텐츠를 감싸는 최상위 컨테이너 `<div class="eventBox">`이다
- **콘텐츠_정보**: `contentName`, `contentCode`, `linkObj` 등 HTML `<head>` 내 스크립트에 정의된 메타데이터이다
- **디바이스_모드**: 미리보기 화면의 표시 너비를 모바일(MO) 또는 PC 기준으로 전환하는 설정이다
- **플로팅_패널**: 이미지 교체, 링크 편집 등 세부 속성을 수정하기 위해 클릭 시 나타나는 팝업 형태의 편집 UI이다

## 요구사항

### 요구사항 1: ZIP 파일 업로드 및 파싱

**사용자 스토리:** 롯데백화점 직원으로서, 기존 작업된 HTML ZIP 파일을 업로드하여 에디터에서 편집을 시작하고 싶다.

#### 인수 조건

1. WHEN 사용자가 ZIP 파일을 드래그 앤 드롭하거나 파일 선택 버튼을 클릭하여 업로드하면, THE ZIP_파서 SHALL ZIP 파일 내부의 모든 파일을 메모리에 로드하고 디렉터리 구조를 파싱한다
2. WHEN ZIP 파일 내에 index.html 파일이 존재하면, THE ZIP_파서 SHALL index.html의 DOM 구조를 분석하여 eventBox 내부의 소스_영역 목록을 추출한다
3. WHEN ZIP 파일 내에 images/ 폴더가 존재하면, THE ZIP_파서 SHALL 모든 이미지 파일을 Blob URL로 변환하여 미리보기에 사용할 수 있도록 매핑한다
4. IF 업로드된 파일이 ZIP 형식이 아니면, THEN THE 에디터 SHALL "ZIP 파일만 지원됩니다" 오류 메시지를 표시한다
5. IF ZIP 파일 내에 index.html이 존재하지 않으면, THEN THE 에디터 SHALL "index.html 파일이 포함되어야 합니다" 오류 메시지를 표시한다
6. WHEN ZIP 파일 파싱이 진행 중이면, THE 에디터 SHALL 로딩 인디케이터와 현재 처리 상태 텍스트를 표시한다
7. WHEN ZIP 파일 내에 중첩 폴더(예: html_999999sn/index.html)가 존재하면, THE ZIP_파서 SHALL 중첩 폴더를 루트로 인식하여 정상적으로 파싱한다

### 요구사항 2: HTML 콘텐츠 미리보기

**사용자 스토리:** 롯데백화점 직원으로서, 업로드한 HTML 콘텐츠가 실제 APP/홈페이지에서 어떻게 보이는지 미리 확인하고 싶다.

#### 인수 조건

1. WHEN ZIP 파싱이 완료되면, THE 미리보기_영역 SHALL eventBox 내부의 모든 소스_영역을 원본 HTML 구조와 동일한 순서로 렌더링한다
2. WHEN 탭_구성이 포함된 HTML이 로드되면, THE 미리보기_영역 SHALL 탭 버튼 영역과 각 탭의 콘텐츠 영역을 구분하여 표시하고, 탭 클릭 시 해당 콘텐츠를 전환한다
3. WHEN 슬라이드_블록이 포함된 HTML이 로드되면, THE 미리보기_영역 SHALL 슬라이드 이미지를 좌우 탐색 가능한 형태로 표시하고 현재 슬라이드 인덱스를 표시한다
4. WHEN 사용자가 디바이스_모드를 MO로 설정하면, THE 미리보기_영역 SHALL 미리보기 너비를 모바일 기준(390px)으로 표시한다
5. WHEN 사용자가 디바이스_모드를 PC로 설정하면, THE 미리보기_영역 SHALL 미리보기 너비를 PC 기준(최대 900px)으로 확장하여 표시한다
6. THE 미리보기_영역 SHALL 각 소스_영역 위에 마우스를 올리면 해당 영역의 유형(이미지, 링크, 슬라이드, 텍스트)을 색상 테두리로 구분하여 표시한다

### 요구사항 3: 이미지 블록 편집

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠 내 이미지를 로컬 파일로 교체하여 새로운 이미지를 반영하고 싶다.

#### 인수 조건

1. WHEN 사용자가 이미지_블록을 클릭하면, THE 에디터 SHALL 이미지 교체를 위한 플로팅_패널을 표시한다
2. WHEN 사용자가 플로팅_패널에서 새 이미지 파일을 선택하면, THE 에디터 SHALL 선택된 이미지를 미리보기_영역에 즉시 반영하고 내부 파일 매핑을 갱신한다
3. WHEN 사용자가 이미지를 교체하면, THE 에디터 SHALL 원본 파일 경로를 유지하면서 이미지 데이터만 교체한다
4. THE 에디터 SHALL 이미지_블록의 alt 속성을 플로팅_패널에서 편집할 수 있도록 입력 필드를 제공한다
5. WHEN 이미지가 교체되면, THE 에디터 SHALL 상단 바에 "변경됨" 표시를 활성화한다

### 요구사항 4: 링크 블록 편집

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠 내 링크 이미지의 연결 URL과 링크 속성을 수정하고 싶다.

#### 인수 조건

1. WHEN 사용자가 링크_블록을 클릭하면, THE 에디터 SHALL 링크 편집을 위한 플로팅_패널을 표시하고, 현재 링크 유형(BrowserOpen, shopping, event, sso)과 URL 값을 표시한다
2. WHEN 사용자가 플로팅_패널에서 링크 유형을 변경하면, THE 에디터 SHALL linkObj 배열의 해당 항목의 type 값을 갱신한다
3. WHEN 사용자가 플로팅_패널에서 URL 값을 변경하면, THE 에디터 SHALL linkObj 배열의 해당 항목의 url 값을 갱신한다
4. WHEN 사용자가 플로팅_패널에서 버튼명을 변경하면, THE 에디터 SHALL linkObj 배열의 해당 항목의 value 값을 갱신한다
5. THE 에디터 SHALL 링크_블록의 이미지도 이미지_블록과 동일한 방식으로 교체할 수 있도록 이미지 업로드 기능을 플로팅_패널에 포함한다

### 요구사항 5: 슬라이드 블록 편집

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠 내 슬라이드 영역의 이미지를 추가·삭제·교체하고 싶다.

#### 인수 조건

1. WHEN 사용자가 슬라이드_블록을 클릭하면, THE 에디터 SHALL 슬라이드 관리 사이드 패널을 열어 모든 슬라이드 이미지 목록을 표시한다
2. WHEN 사용자가 사이드 패널에서 "슬라이드 추가" 버튼을 클릭하면, THE 에디터 SHALL 새 슬라이드 항목을 목록 끝에 추가하고 이미지 업로드 영역을 표시한다
3. WHEN 사용자가 슬라이드 항목의 삭제 버튼을 클릭하면, THE 에디터 SHALL 해당 슬라이드를 목록에서 제거하고 미리보기_영역을 갱신한다
4. WHEN 사용자가 슬라이드 항목에 새 이미지를 업로드하면, THE 에디터 SHALL 해당 슬라이드의 이미지를 교체하고 미리보기_영역에 즉시 반영한다
5. WHEN 슬라이드_블록에 슬라이드가 1개만 남은 상태에서 삭제를 시도하면, THE 에디터 SHALL 삭제를 차단하고 "최소 1개의 슬라이드가 필요합니다" 메시지를 표시한다
6. WHEN 에디터에서 새 슬라이드를 삽입하면, THE 에디터 SHALL 블록형(block-type) 슬라이드로 렌더링하여 이미지를 세로로 쌓아 표시하고, 내보내기 시 개별 `<img>` 태그로 출력한다. 원본 ZIP에서 가져온 슬라이드는 swiper 뷰포트(좌우 넘기기) 형태를 유지한다.

### 요구사항 6: 소스 영역 추가

**사용자 스토리:** 롯데백화점 직원으로서, 기존 콘텐츠에 새로운 이미지나 슬라이드 영역을 추가하고 싶다.

#### 인수 조건

1. THE 에디터 SHALL 각 콘텐츠 영역의 하단에 "이미지 삽입" 또는 "슬라이드 삽입" 버튼을 하나의 삽입 존(insert zone)으로 표시한다. (구현 변경: 모든 아이템 사이가 아닌, 각 콘텐츠 영역 하단에만 1개의 삽입 존을 배치)
2. WHEN 사용자가 "이미지 삽입" 버튼을 클릭하면, THE 에디터 SHALL 해당 위치에 새 이미지_블록을 추가하고 이미지 업로드 플로팅_패널을 표시한다
3. WHEN 사용자가 "슬라이드 삽입" 버튼을 클릭하면, THE 에디터 SHALL 해당 위치에 새 슬라이드_블록을 추가하고 슬라이드 관리 패널을 표시한다
4. WHEN 탭_구성이 없는 콘텐츠에서도 THE 에디터 SHALL 콘텐츠 영역 하단에 삽입 버튼을 표시한다

### 요구사항 7: 소스 영역 삭제

**사용자 스토리:** 롯데백화점 직원으로서, 불필요한 소스 영역을 콘텐츠에서 제거하고 싶다.

#### 인수 조건

1. WHEN 사용자가 소스_영역 위에 마우스를 올리면, THE 에디터 SHALL 해당 영역의 우측 상단에 삭제 버튼을 표시한다
2. WHEN 사용자가 삭제 버튼을 클릭하면, THE 에디터 SHALL 해당 소스_영역을 콘텐츠에서 제거하고 미리보기_영역을 갱신한다
3. IF eventBox 내에 소스_영역이 1개만 남은 상태에서 삭제를 시도하면, THEN THE 에디터 SHALL 삭제를 차단하고 "최소 1개의 콘텐츠 영역이 필요합니다" 메시지를 표시한다

### 요구사항 8: 소스 영역 순서 변경

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠 내 소스 영역의 표시 순서를 변경하고 싶다.

#### 인수 조건

1. THE 에디터 SHALL 탭 내부 또는 탭이 없는 구조에서 소스_영역의 순서를 드래그 앤 드롭 또는 위/아래 이동 버튼으로 변경할 수 있는 기능을 제공한다
2. WHEN 소스_영역의 순서가 변경되면, THE 에디터 SHALL 미리보기_영역의 렌더링 순서를 즉시 갱신한다
3. WHEN 소스_영역의 순서가 변경되면, THE 에디터 SHALL 내부 DOM 구조와 이미지 경로 매핑을 순서에 맞게 갱신한다

### 요구사항 9: 탭 구성 관리

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠의 탭을 추가·삭제하고 탭 버튼 이미지를 교체하고 싶다.

#### 인수 조건

1. WHEN 사용자가 탭 추가 버튼을 클릭하면, THE 에디터 SHALL 새 탭을 탭_구성 끝에 추가하고, 탭 버튼 이미지(on/off) 업로드와 탭 콘텐츠 편집 영역을 제공한다
2. WHEN 사용자가 탭 버튼 위에 마우스를 올리고 삭제 버튼을 클릭하면, THE 에디터 SHALL 해당 탭과 연결된 콘텐츠 영역을 함께 제거한다
3. IF 탭이 1개만 남은 상태에서 삭제를 시도하면, THEN THE 에디터 SHALL 삭제를 차단하고 "최소 1개의 탭이 필요합니다" 메시지를 표시한다
4. WHEN 사용자가 탭 버튼을 클릭하면, THE 에디터 SHALL 탭 관리 패널을 표시하여 각 탭의 on/off 이미지를 교체할 수 있도록 한다
5. WHEN 탭이 추가 또는 삭제되면, THE 에디터 SHALL 탭 버튼 영역의 너비 비율을 탭 개수에 맞게 자동 조정한다(2개: 50%, 3개: 33.33%, 4개: 25%, 5개: 20%)

### 요구사항 10: 콘텐츠 정보 편집

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠의 메타데이터(콘텐츠명, 태깅코드)를 수정하고 싶다.

#### 인수 조건

1. WHEN 사용자가 "콘텐츠 정보" 버튼을 클릭하면, THE 에디터 SHALL 콘텐츠_정보 편집 패널을 표시하고 현재 contentName과 contentCode 값을 입력 필드에 표시한다
2. WHEN 사용자가 contentName 값을 수정하면, THE 에디터 SHALL 내부 데이터의 contentName을 갱신한다
3. WHEN 사용자가 contentCode 값을 수정하면, THE 에디터 SHALL 내부 데이터의 contentCode를 갱신한다
4. WHEN 콘텐츠_정보가 수정되면, THE 에디터 SHALL 변경 사항을 ZIP 내보내기 시 index.html의 `<head>` 스크립트 영역에 반영한다

### 요구사항 11: ZIP 파일 내보내기

**사용자 스토리:** 롯데백화점 직원으로서, 편집 완료된 콘텐츠를 원본과 동일한 ZIP 형식으로 다운로드하여 통합 관리자에 업로드하고 싶다.

#### 인수 조건

1. WHEN 사용자가 "ZIP 저장" 버튼을 클릭하면, THE ZIP_생성기 SHALL 편집된 콘텐츠를 원본 ZIP과 동일한 디렉터리 구조(index.html, css/, js/, images/)로 조립한다
2. THE ZIP_생성기 SHALL 교체된 이미지 파일을 원본 경로에 새 이미지 데이터로 저장한다
3. THE ZIP_생성기 SHALL 추가된 소스_영역의 이미지를 적절한 images/ 하위 경로에 포함한다
4. THE ZIP_생성기 SHALL 삭제된 소스_영역의 이미지를 ZIP에서 제외한다
5. THE ZIP_생성기 SHALL 편집된 index.html의 DOM 구조와 `<head>` 스크립트(contentName, contentCode, linkObj)를 반영하여 저장한다
6. THE ZIP_생성기 SHALL 원본 ZIP에 포함된 css/, js/ 파일을 변경 없이 그대로 포함한다
7. WHEN ZIP 생성이 완료되면, THE 에디터 SHALL 브라우저의 파일 다운로드 기능을 통해 ZIP 파일을 자동으로 다운로드한다
8. WHEN ZIP 내보내기가 진행 중이면, THE 에디터 SHALL 로딩 인디케이터를 표시하고 "ZIP 저장" 버튼을 비활성화한다

### 요구사항 12: 텍스트 편집

**사용자 스토리:** 롯데백화점 직원으로서, 콘텐츠 내 텍스트(alt 속성, 인라인 텍스트)를 직접 수정하고 싶다.

#### 인수 조건

1. WHEN 사용자가 편집 가능한 텍스트 요소를 클릭하면, THE 에디터 SHALL 해당 텍스트를 인라인 편집 모드로 전환하고 텍스트 편집 툴바를 표시한다
2. WHEN 사용자가 텍스트 편집 툴바에서 "확인" 버튼을 클릭하면, THE 에디터 SHALL 변경된 텍스트를 저장하고 인라인 편집 모드를 종료한다
3. WHEN 사용자가 텍스트 편집 툴바에서 "취소" 버튼을 클릭하면, THE 에디터 SHALL 텍스트를 원래 값으로 복원하고 인라인 편집 모드를 종료한다

### 요구사항 13: 에디터 초기화

**사용자 스토리:** 롯데백화점 직원으로서, 편집 내용을 모두 취소하고 원본 상태로 되돌리고 싶다.

#### 인수 조건

1. WHEN 사용자가 "초기화" 버튼을 클릭하면, THE 에디터 SHALL 모든 편집 내용을 취소하고 원본 ZIP 파일의 상태로 미리보기_영역을 복원한다
2. WHEN 초기화가 완료되면, THE 에디터 SHALL "변경됨" 표시를 비활성화한다

### 요구사항 14: 브라우저 단독 실행

**사용자 스토리:** 롯데백화점 직원으로서, 별도 프로그램 설치 없이 HTML 파일을 브라우저에서 열어 바로 에디터를 사용하고 싶다.

#### 인수 조건

1. THE 에디터 SHALL 단일 HTML 파일로 구성되어 브라우저에서 직접 열어 실행할 수 있어야 한다
2. THE 에디터 SHALL 서버, 데이터베이스, 로그인 기능 없이 클라이언트 측에서만 동작한다
3. THE 에디터 SHALL JSZip 라이브러리를 CDN을 통해 로드하여 ZIP 파일 처리를 수행한다
4. THE 에디터 SHALL 모든 UI 텍스트, 버튼 레이블, 오류 메시지, 코드 주석을 한국어로 표시한다

### 요구사항 15: 다양한 HTML 구조 호환

**사용자 스토리:** 롯데백화점 직원으로서, 탭이 있는 구조와 없는 구조 등 다양한 형태의 HTML 콘텐츠를 모두 편집하고 싶다.

#### 인수 조건

1. WHEN 탭_구성이 포함된 ZIP 파일이 업로드되면, THE 에디터 SHALL 탭 버튼 영역과 각 탭별 콘텐츠 영역을 분리하여 편집 가능하게 표시한다
2. WHEN 탭_구성이 없는 ZIP 파일이 업로드되면, THE 에디터 SHALL eventBox 내부의 이미지와 슬라이드를 순차적으로 편집 가능하게 표시한다
3. WHEN 2개 이상 5개 이하의 탭이 포함된 HTML이 업로드되면, THE 에디터 SHALL 모든 탭을 정상적으로 인식하고 편집 기능을 제공한다
4. WHEN basic-tab 유형의 탭이 포함된 HTML이 업로드되면, THE 에디터 SHALL 기본 탭 레이아웃으로 표시한다
5. WHEN swiper-tab 유형의 탭이 포함된 HTML이 업로드되면, THE 에디터 SHALL 스와이프 탭 레이아웃으로 표시한다
6. WHEN 링크_블록이 포함된 HTML이 업로드되면, THE 에디터 SHALL 링크 이미지를 별도 색상(분홍색 테두리)으로 구분하여 표시하고 링크 편집 기능을 제공한다

### 요구사항 16: 변경 상태 추적

**사용자 스토리:** 롯데백화점 직원으로서, 현재 편집 내용이 원본과 달라졌는지 확인하고 싶다.

#### 인수 조건

1. WHEN 사용자가 소스_영역을 추가, 삭제, 교체, 순서 변경하면, THE 에디터 SHALL 상단 바에 "변경됨" 배지를 표시한다
2. WHILE 변경 사항이 존재하면, THE 에디터 SHALL "ZIP 저장" 버튼과 "초기화" 버튼을 활성화 상태로 유지한다
3. WHILE 변경 사항이 존재하지 않으면, THE 에디터 SHALL "ZIP 저장" 버튼과 "초기화" 버튼을 비활성화 상태로 유지한다

### 요구사항 17: 사용자 피드백 알림

**사용자 스토리:** 롯데백화점 직원으로서, 편집 작업의 성공·실패 여부를 즉시 확인하고 싶다.

#### 인수 조건

1. WHEN 이미지 교체, 슬라이드 추가, 탭 추가 등의 작업이 성공하면, THE 에디터 SHALL 화면 상단에 성공 토스트 메시지(녹색)를 2초간 표시한다
2. IF 파일 형식 오류, 필수 조건 미충족 등의 문제가 발생하면, THEN THE 에디터 SHALL 화면 상단에 오류 토스트 메시지(빨간색)를 2초간 표시한다
3. WHEN 정보성 안내가 필요하면, THE 에디터 SHALL 화면 상단에 정보 토스트 메시지(보라색)를 2초간 표시한다
